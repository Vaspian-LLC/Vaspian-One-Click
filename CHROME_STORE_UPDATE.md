# Chrome Web Store update: version 2.0.0

## Package

Build from the `feat/v2` branch with tests, promo, screenshots, store notes and `test-click-to-call.html` left out of the zip.

## Release notes (for the store submission)

```
Version 2.0.0

- Call card: see who's calling, then answer, hold, transfer, park or hang up from Chrome.
- Team tab: coworkers' status, ring groups and parked calls.
- Do not disturb and forwarding at the top of the panel.
- Screen pop to Simplicity Collect, Zoho Desk, SecureCRM or any web address.
- History with filters, notes and optional after-call wrap-up.
- Team view for receptionists with administrator access.
- Keyboard shortcuts: Alt+Shift+A answer, Alt+Shift+H hang up, Alt+Shift+D Do not disturb, Alt+Shift+C call the selected number.
- Settings reorganized: Account, Calling, Team view, Screen pop, Wrap-up, Help and support.
- Company-wide settings through Chrome policy.
```

## Permissions added since 1.x

`alarms`, `contextMenus`, optional `notifications`, and managed storage. Explain them with the table in PRIVACY_POLICY.md.

## Privacy fields

Update the store's privacy answers to match PRIVACY_POLICY.md: the Extension handles personal communications (call history) and authentication information (PIN, kept on the device), does not sell data, and uses data only for its single purpose.
